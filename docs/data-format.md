# 数据源格式说明

Amber 读两个目录，都在 `config.json` 里配置，也可以在页面的「数据源」面板里改：

| 配置项 | 必填 | 内容 |
| --- | --- | --- |
| `entriesDir` | 是 | 条目笔记，每部作品一篇 `.md` |
| `coversDir` | 否 | 封面图片 |

两个目录都只读。

## 目录结构

典型的 Obsidian 库布局（目录名随意，只要路径配对）：

```
MyVault/
└── 12媒体档案/
    ├── 动漫/
    │   └── entries/          ← entriesDir
    │       ├── 葬送的芙莉莲.md
    │       └── ...
    └── assets/
        └── covers/           ← coversDir
            ├── 动漫-葬送的芙莉莲.jpg
            └── ...
```

- 只扫描 `entriesDir` **第一层**的 `.md` 文件（扩展名不区分大小写），不进子目录
- 没有 frontmatter 或 frontmatter 里没有 `title` 的笔记会被跳过
- 条目 ID 就是文件名去掉 `.md`

## frontmatter 字段

笔记开头用 `---` 包起来的 YAML。解析器是简化版，支持：

- `key: value`，值两侧的单引号或双引号会被去掉
- 块式数组：

  ```yaml
  tags:
    - 动漫
    - 治愈
  ```

- `tags`、`aliases` 还支持行内数组 `tags: [动漫, 治愈]`（其他字段里的方括号按普通文本处理，避免把「[推子]」这样的标题拆开）

不支持多行字符串（`|`、`>`）和嵌套对象。

| 字段 | 必填 | 类型 | 缺省 | 用途 |
| --- | --- | --- | --- | --- |
| `title` | **是** | 文本 | — | 标题，用于显示、搜索、排序 |
| `media_type` | 否 | 文本 | `动漫` | 媒体类型 |
| `status` | 否 | 文本 | 空 | `看完` / `在看` / `搁置` / `弃坑` 有专门的颜色和筛选按钮；其他值也会显示，但不出现在筛选里 |
| `rating` | 否 | 数字 | 无 | 我的评分，可带小数；空值或非数字视为未评分 |
| `year` | 否 | 整数 | 无 | 作品年份，决定年代长廊的位置和年份排序 |
| `episodes` | 否 | 整数 | 无 | 集数 |
| `favorite` | 否 | 布尔 | `false` | `true` 或 `yes`（不区分大小写）算收藏 |
| `source` | 否 | 文本 | 空 | 来源，例如 `Bangumi` |
| `external_id` | 否 | 文本 | 空 | 来源站的条目 ID |
| `link` | 否 | URL | 空 | 详情页的跳转链接 |
| `tags` | 否 | 数组 | `[]` | 标签，参与搜索；写成单个文本时当作一个标签 |
| `created` | 否 | 日期 | 空 | 记录时间，`YYYY-MM-DD`，用于「记录时间」排序和卡片上的「记录于」 |
| `updated` | 否 | 日期 | 空 | 更新时间 |
| `cover_file` | 否 | 路径 | 空 | 本地封面，见下节 |
| `cover` | 否 | URL | 空 | 远程封面，本地封面找不到时使用（需要联网） |

其他字段（如 `type`、`original_title`、`progress`）会被忽略，留着也没关系。

## 封面查找

1. 取 `cover_file` 的**文件名部分**（前面的目录全部丢掉），在 `coversDir` 里找同名文件。比如 `cover_file: 12媒体档案/assets/covers/动漫-葬送的芙莉莲.jpg` 会找 `coversDir/动漫-葬送的芙莉莲.jpg`
2. 找到了，页面通过 `/covers/{文件名}` 读取；导出分享卡也只用这张本地图
3. 找不到或没配 `coversDir`，海报墙和详情页回退到 `cover` 的远程地址；年代长廊的缩略图和分享卡不显示封面

支持 `.jpg` / `.jpeg` / `.png` / `.webp` / `.gif`。

## 正文小节

正文里两个二级（或任意级别）标题下的内容会被提取：

| 标题 | 用途 |
| --- | --- |
| `## 短评` | 详情页「短评」、年代长廊摘句、分享卡正文 |
| `## 记忆点` | 详情页「记忆点」 |

规则：从标题下一行开始，到下一个任意级别的标题为止；空行和图片嵌入行（`![...]`）会被跳过，其余行去掉首尾空格后用换行拼接。标题文字必须完全一致。其他小节不读。

## 最小示例

文件 `entriesDir/葬送的芙莉莲.md`：

```markdown
---
title: 葬送的芙莉莲
status: 看完
rating: 9
year: 2023
episodes: 28
tags: [动漫, 奇幻]
created: 2024-03-30
---

## 短评

时间很长，所以要好好记住每一个人。

## 记忆点

- 花田魔法
```

这篇会解析成：标题「葬送的芙莉莲」、看完、9 分、2023 年、28 集、标签「动漫」「奇幻」，短评一句，记忆点一行。

## 常见问题

**保存时提示「没有任何 .md 带 title frontmatter」**
确认填的是放笔记的那一层目录，而不是它的上级；以及 frontmatter 第一行必须是 `---`，且在文件最开头。

**有的笔记没出现**
检查它有没有 `title`，以及是不是放在子目录里（子目录不扫描）。

**封面不显示**
看 `cover_file` 的文件名和 `coversDir` 里的文件是否完全一致（包括扩展名），并确认「数据源」面板里封面目录检测通过。

**改了笔记要重启吗**
不用，刷新页面就会重扫。
